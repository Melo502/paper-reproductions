## 📁 仓库结构

```
paper-reproductions/
├── README.md              # 本文件：论文列表与复现状态
├── LICENSE
├── .gitignore
└── MOECLF/                # 每篇论文一个文件夹
    ├── README.md          # 论文信息、复现进度、如何运行
    ├── Code/              # 复现代码
    └── Notion/            # 精读笔记与插图
        ├── 阅读笔记.md
        └── DRL增强EA笔记/
            ├── DRL增强EA学习笔记.md
            └── images/
```

文件夹命名规则：使用论文方法简称，不带空格；已建目录沿用原名（如 `MOECLF`）。

每个论文文件夹内约定：

- `README.md`：论文信息、复现目标、运行方法、结果对比
- `Code/`：复现代码
- `Notion/`：精读笔记，插图统一放 `Notion/images/`
- `data/`、`results/`：数据与实验输出，不入库（已在 `.gitignore` 中忽略）

## 🚀 如何运行

每个文件夹相互独立，进入对应目录后按其中的 README 操作即可。通用流程如下：

```bash
# 1. 克隆仓库
git clone https://github.com/Melo502/paper-reproductions.git
cd paper-reproductions

# 2. 进入某篇论文的文件夹
cd MOECLF

# 3. 安装依赖（建议使用虚拟环境）
pip install -r requirements.txt

# 4. 按该文件夹 README 里的命令运行
python main.py
```

> 当前 `MOECLF/` 仅有笔记与框架梳理，代码尚未提交，`requirements.txt` 与运行命令待补。

## 📝 每篇复现的 README 包含什么

每个论文文件夹的 README 尽量包含以下内容：

1. 论文标题、作者、年份、原文链接
2. 复现目标（复现论文中的哪些表格或图）
3. 环境与依赖
4. 数据集来源与下载方式
5. 运行命令（训练、评估各一条）
6. 结果对比（论文数值与复现数值）
7. 与论文的差异及可能原因
8. 参考资料（官方代码、相关博客等）

## ➕ 添加新论文的步骤

1. 在「计划中」表格里添加一行
2. 新建以论文简称命名的文件夹，并写好该文件夹的 README
3. 开始复现，把状态改为「进行中」
4. 完成后，把该行移到「已完成」，并补上结果
